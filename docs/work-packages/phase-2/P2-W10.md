# P2-W10 — Canonical event and evidence envelope

## 1. Purpose

Fix the shape of "something happened at a decoy" before four packs start
emitting it and three more packages start reading it.

## 2. Scope

1. `schemas/event/v1/canonical-event.schema.json`, carrying `EV-02`'s approved
   field list.
2. `apps/control-plane/internal/event`: the Go type, the validator, and the
   ingest-time stamping.
3. The identifier rule behind `AC-EV-001`, with a bounded in-process
   deduplicator.

## 3. The three decisions worth arguing about

**The envelope carries a reference, never the evidence.** `EV-03` bounds what is
retained and stores it separately. An envelope that could hold a transcript
would put an attacker's bytes into every index, log line, and console that
touches an event, and `raw_ref` is what keeps them in one place instead.

**There is nowhere to put a credential.** `EV-03` requires credential material
to be protected or redacted. Rather than a rule someone has to remember, the
type has no field for a secret: `auth` carries the identity offered and the
result, and `synthetic_credential_id` names a credential *Guardian planted*
rather than one an attacker supplied. Asserted structurally in Go and again on
the contract.

**`ingested_time` is the Control Plane's.** An Edge that could assert when its
event was accepted could backdate one past a retention boundary. An event
arriving with it set is refused with its own error — a trust-boundary violation
rather than a formatting mistake. `edge_id` is the same idea enforced one layer
up: ingest takes it from the authenticated device identity, so one Edge cannot
attribute an event to another.

## 4. Acceptance

- **AC-EV-001** — `event_id` is assigned once at capture and stable across
  retries. `Deduplicator` rejects a repeat. The durable half is a unique
  constraint at ingest and belongs to `P2-W12`: this makes a duplicate
  *detectable*, the database makes it *impossible*, and the package does not
  pretend otherwise.
- **AC-EV-002** — edge, decoy, runtime, schema, and raw reference are all
  expressible and asserted. `provenance.source_path` additionally records
  whether a native typed path or a third-party log parser produced the event,
  because those do not warrant equal confidence.
- **AC-EV-003** — all three timestamps are kept, and `observed_time` may not
  precede `event_time`: an adapter cannot have seen an interaction before it
  happened.
- **AC-SEC-008** — the size bound is checked before decoding, so an oversized
  payload is refused before anything allocates for it. Oversized, truncated,
  non-JSON, empty, wrong-typed, and deeply nested inputs are all asserted not to
  panic.

## 5. Non-goals

- **No transport.** `P2-W12` owns the spool, the acknowledgements, and the
  durable idempotency constraint.
- **No adapters.** `P2-W11` produces events; this says what one is.
- **No storage.** No table, no blob store; `P2-W13` owns those.
- **No console surface.** `WCX-12` and `WCX-13` read evidence.
