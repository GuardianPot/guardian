# P2-W11 — Edge normalization adapters

## 1. Purpose

Turn what a decoy pack produces into canonical events, on the assumption that
the input is hostile — because it is. A Cowrie session log records what an
attacker typed; an HTTP access line records the path they asked for.

## 2. Architecture

Two paths and one pipeline.

**Native typed path.** A pack Guardian ships writes canonical events to a
socket the Edge owns.

**Log adapter path.** A third-party pack writes its own log format and the Edge
reads it, one bounded line at a time.

Both converge on the same bounds, the same validation, the same deduplication,
and the same closed set of reasons for throwing something away. The two are
distinguishable afterwards: `provenance.source_path` records which one produced
the event, because a typed event from Guardian's own pack and a line parsed out
of third-party software are not equally strong claims.

## 3. The order in the pipeline is the security property

1. **Size, before anything parses.** An oversized payload costs a length
   comparison. `AC-SEC-008` is mostly this.
2. **The adapter, inside a recover.** An adapter indexes into text an attacker
   wrote. A slice bound it got wrong is a panic, and that must not take the
   Edge with it, so it becomes `adapter_failed` — a reason that tells an
   operator they are looking at a Guardian bug rather than at an attack.
3. **Validation, before deduplication.** A malformed identifier must not enter
   the dedup window.
4. **Deduplication, before rate limiting.** A retry storm is recognised as
   retries rather than eating the budget a real burst needs.
5. **Rate limiting last**, as a token bucket: a burst is a real attacker doing
   a lot at once and should get through; a sustained flood is a broken pack or
   an attempt to fill the spool, and is held.

## 4. What is kept and what is not

A malformed payload is quarantined: it is evidence of a pack change, an adapter
bug, or someone probing the parser, and dropping it silently throws that away.
What is kept is bounded and marked as truncated, because the material is
attacker-controlled and keeping all of it would let the attacker choose how much
disk a malformed event costs. It is never re-parsed.

A rate-limited event is *not* quarantined. It is well-formed and unremarkable,
and keeping every one of them is how a burst becomes a disk problem.

## 5. Provenance is the pipeline's, not the adapter's

An adapter cannot say which path it came through. The pipeline overwrites
`source_path` and `adapter` after the adapter returns, because an adapter that
could label a parsed log line `native_uds` would be inflating the confidence a
reader places in it, and `SRC-07` is about exactly that.

## 6. Acceptance

- **AC-SEC-008** and the package's own criterion — oversized, truncated,
  non-JSON, empty, wrong-typed, deeply nested, and invalid-UTF-8 inputs are each
  asserted not to panic, as is a deliberately panicking adapter. A 100 KB log
  line is refused without being assembled, and the lines around it still arrive.
- **AC-EV-001**, the Edge half — a retry is recognised before it is spooled.
  The durable constraint remains `P2-W12`'s.

## 7. Non-goals

- **No pack parsers.** `P2-W5` through `P2-W8` know their own formats; this is
  the seam they fill and the bounds they inherit.
- **No spool or transport.** `P2-W12` owns those.
- **No blob storage.** The quarantine seam is an interface here; `P2-W13` owns
  where the bytes land.
