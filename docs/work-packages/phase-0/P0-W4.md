# P0-W4 — Build reproducible isolated network lab

- Status: IN PROGRESS
- Risk: High
- Dependency: P0-W1
- Primary component: Lab
- Owner: `@sinanganiz`

## Scope

Edge VM, attacker host, two routed zones, isolation, and deterministic reset.
Use only a privileged disposable runner or an explicitly owned local lab.

## Acceptance evidence

- reproducible setup and reset;
- routing and isolation tests;
- no unauthorized network exposure;
- security review.

Implementation is currently scoped to the Docker Desktop Linux engine with
Docker/WSL2 as the repeatable baseline. The Hyper-V Debian 13 profile is
documented as a second manual validation path in `deploy/lab/README.md`.
