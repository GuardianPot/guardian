# Architecture change proposals

Use a change proposal when a work package would alter approved product scope,
architecture, a contract, a trust boundary, a privileged capability, a
runtime/datastore/message broker, or an acceptance criterion.

## Lifecycle

`OPEN → RESEARCHED → RECOMMENDED → OWNER DECISION → APPROVED`

An agent can create or update a proposal through `RECOMMENDED`. Only
`@sinanganiz` can record `OWNER DECISION` and `APPROVED`.
