# Change proposals (historical)

These nine documents are the record of decisions already made. They are kept
because ADRs and work packages cite them by path, and because the reasoning is
still worth reading.

The proposal *process* — the `OPEN → RESEARCHED → RECOMMENDED → OWNER DECISION
→ APPROVED` lifecycle and its template — is retired. New decisions worth
recording go in `docs/adr/` as a short ADR. Nothing new is added here.
